What it does

A Linux environment that fits in your pocket.

Linexa is a workspace manager, not an emulator. Each workspace has its own root filesystem, sessions, packages, and settings.

Isolated workspaces

Run multiple Linux environments and switch between them. Each keeps its own files and configuration.

RootFS installer

Import a .tar.gz, .tar.xz, or .tar.zst archive, or download Alpine, Ubuntu, Arch Linux ARM, Debian, or Fedora.

Real PTY terminal

ANSI/cursor rendering, scrollback, selection, copy/paste, pinch-to-zoom, and an extra-keys row.

Package manager

Search, install, update, and remove packages through apt, pacman, apk, dnf, or zypper.

Files and SAF

Browse, edit, import, and export files. The Storage Access Framework provider works without all-files access.

Optional desktop

Connect through the built-in VNC client or a local WebView. VNC mode needs Xvnc inside the guest.

Install

Direct download, four steps.

Linexa is distributed as a signed APK from GitHub Releases. There is no account and no in-app updater.

  1. Download the APK from the release page.
  2. Allow installs from your browser or file manager when Android asks. This is the normal sideload warning.
  3. Open the APK and install it.
  4. Launch Linexa, choose Add a workspace, then import a RootFS archive or download a distribution.
Beta notice. Interfaces, supported guests, and device behaviour may change. Back up important workspace data before upgrading. Linexa does not require root; PRoot provides a user-space guest environment. The app itself runs with ordinary Android permissions.
Automatic update checks (optional). Add github.com/ForExample25/Linexa to Obtainium to be notified when a new GitHub release is published. Obtainium is a separate open-source app; Linexa itself still has no account, no telemetry, and no built-in updater.

Privacy

Local-first by design.

No analytics, advertising, crash reporting, or tracking SDKs. Workspace metadata stays in Room on your device.

No account. There is no sign-up, login, or cloud sync.

Network only when you choose. RootFS downloads go to public distribution mirrors after you tap Download. Guest software controls its own traffic.

No data sale. We do not receive your workspace data.
